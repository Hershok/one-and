# One &

A talking metronome that counts **1 & 2 & 3 & 4 &** (and **1 & 2 & 3 &** in 3/4).

Voice: Orion, with a lifted **&** on the upbeat.

## Features

- 30–200 BPM
- 4/4 and 3/4
- Eighth-note count by default; optional sixteenths (`1 e & a`)
- Click on/off
- Voice on/off
- Count-in: off, short (`3 & 4 &` or `2 & 3 &` in 3/4), or 2 full bars
- Dark screen, large beat display
- Works on a computer and iPhone (Safari → Add to Home Screen)

## Try it on your computer first

1. Download this folder.
2. Open `index.html` in Chrome or Edge.
3. Tap **Start**. Your browser will ask to play sound.

Safari can be picky with local files. If the voice does not load from a double-clicked file, use GitHub Pages below — that is the reliable path for iPhone anyway.

## Put it on GitHub Pages (computer + iPhone)

You need a free GitHub account.

### 1. Create a repository

1. Go to [https://github.com/new](https://github.com/new)
2. Repository name: `one-and` (any name is fine)
3. Public
4. Do **not** add a README, .gitignore, or license (this folder already has a README)
5. Create repository

### 2. Upload these files

On the empty repo page:

1. Click **uploading an existing file**
2. Drag **everything inside** this `one-and` folder onto the page  
   You should see `index.html`, `app.js`, `styles.css`, `manifest.json`, `sw.js`, `README.md`, plus the `audio` and `icons` folders
3. Click **Commit changes**

### 3. Turn on GitHub Pages

1. In the repo, open **Settings**
2. Left sidebar: **Pages**
3. Under **Build and deployment → Source**, choose **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)**
5. Save

After a minute, the Pages section will show a URL like:

`https://YOUR-USERNAME.github.io/one-and/`

Open that on your computer and on your iPhone.

### 4. Add it to the iPhone home screen

1. Open the Pages URL in **Safari** (not Chrome)
2. Tap the Share button
3. Tap **Add to Home Screen**
4. Open it from the home screen and press Start

Keep the app in the foreground while it runs. iPhone will not let a browser tab keep counting reliably in the background.

## Change something later

Edit a file on GitHub (**pencil** icon) or upload a replacement file. Pages updates in about a minute.

If the old version seems stuck on the phone, delete the home screen icon, visit the site in Safari, then Add to Home Screen again.
